# Grade Calculator

A Python-based grade calculator for students to enter subjects, grades, and generate a report card.

## Features
- Student name and age input
- Subject entry with percentage or marks
- Automatic percentage conversion from marks
- Default or custom grading thresholds
- Final report card output with subject grades and average
- Input validation for better user experience

## Project Goal
This project was created to help students quickly calculate their academic performance and generate a simple report card.

## How to Run
1. Make sure Python 3 is installed.
2. Open a terminal in the project folder.
3. Run the script:

```bash
python grade_calculator.py
```

## Example Run
When you run the program, it will ask for:
- Name
- Age
- Subject names
- Grade type: percentage or marks
- Grade thresholds

Then it will generate a report card similar to this:

```text
Report Card for John (Age: 15)
========================================
Math                 85.00%  B
Science              90.00%  A
English              75.00%  C
Average              83.33%
========================================
```

## Default Grade Thresholds
* **A:** 90+
* **B:** 80-89
* **C:** 70-79
* **D:** 60-69
* **E:** 50-59
* **U:** Below 50
